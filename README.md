# Optimum Physiotherapy — website preview

Private preview of the proposed website for **Optimum Physiotherapy**,
Suite 108, 1300 Central Pkwy W, Mississauga ON.

Built by [Vital Sign Digital](https://vitalsigndigital.com).

## This is a preview, not the finished site

- Amber **[CONFIRM: …]** tags mark facts only the clinic can supply — fees,
  appointment lengths, insurance wording, practitioner names, parking.
  Nothing has been invented to fill them.
- Canonical tags and structured data carry a **placeholder domain**; they are
  rewritten once the real domain is confirmed.
- Pages use `.html` links here so the site runs from a subfolder. The
  production build uses clean URLs (`/physiotherapy`) via `.htaccess`.

Delete this repository at any time — nothing depends on it.
